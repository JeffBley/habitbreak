# Habit Break

Habit Break is a local-only iOS 17+ SwiftUI app for tracking up to three habits. Days are considered successful by default after tracking begins; users only need to record exceptions.

## Open in Xcode

1. Install [XcodeGen](https://github.com/yonaskolb/XcodeGen) on a Mac with `brew install xcodegen`.
2. Run `xcodegen generate` in this directory.
3. Open `HabitBreak.xcodeproj` in Xcode.
4. Select a development team and run on an iOS 17+ simulator or device.

All data is stored locally with SwiftData. The app has no account, network, analytics, or notification integration.
